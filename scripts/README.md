# Explainer-video scripts: Control Systems (22EEG53) and Basic Electrical & Electronics Engineering

Presenter: Prof. Mitesh Astik. Every script has: hook, learning objectives, concept scenes with on-screen text, animation instructions and AI image/animation prompts, a fully solved numerical, exam tips, a 5-point recap, 2 practice questions with answers, a next-video teaser, plus YouTube title, description with chapters, 10 tags and thumbnail text.

Timings are computed from word count at 140 words per minute. MATLAB lab values were computed independently with SciPy; confirm on your MATLAB installation. Lab experiment 4 (synchro) uses illustrative numbers, not measured data.

## Folder guide
- `Control_Systems/` and `BEEE/`: one Word file per video (two-column script table + YouTube package + series roadmap)
- `narration_txt/`: narration-only text for each video (paste into a text-to-speech tool or teleprompter)
- `YouTube_Metadata_and_AI_Prompts.xlsx` (and CSV copies): titles, descriptions with chapters, tags, thumbnail text, and all scene prompts
