[0:34] SCENE 1: THEORY IN 60 SECONDS
Quick revision. The standard second-order transfer function is omega n squared over s squared plus 2 zeta omega n s plus omega n squared. We take omega n equal to 5 radians per second. If zeta is zero, the response oscillates forever. For zeta between 0 and 1, it is underdamped, overshooting and settling. At zeta equal to 1 it is critically damped, and above 1, overdamped. For the underdamped case, peak overshoot is e to the power minus pi zeta by root of 1 minus zeta squared, peak time is pi by omega d, and settling time is about 4 by zeta omega n.

[1:19] SCENE 2: THE MATLAB CODE, LINE BY LINE
Open a new script in MATLAB. First, define omega n as 5, and a vector of damping ratios: 0, 0.3, 0.6, 1 and 2. Define the time vector from 0 to 6 seconds in steps of 0.001. Then call figure, hold on, and grid on, so that all the curves appear on the same axes.

Now the loop. For each value of zeta, create the transfer function with the tf command. The numerator is omega n squared, and the denominator is the vector 1, 2 zeta omega n, omega n squared. Then call step with the system and the time vector. Add a legend and a title.

To read the specifications, make the transfer function for zeta equal to 0.6, which is 25 over s squared plus 6 s plus 25, and call stepinfo. It returns a structure with the rise time, settling time, overshoot, peak and peak time. The pole command lists the closed-loop poles.

If MATLAB shows an error saying undefined function tf, you need the Control System Toolbox. Check with the lab instructor.

[2:34] SCENE 3: SIMULINK MODEL
The same experiment in Simulink. Drag a Step block, a Transfer Function block, and a Scope onto the canvas. Connect them in this order. Double click the Transfer Function block, type 25 as the numerator and 1, 6, 25 as the denominator. Set the stop time to 6 seconds and press run. Open the scope to see the response. Change the denominator to try other damping ratios.

[4:00] LIVE DEMO: WORKED EXAMPLE AND EXPECTED RESULTS
Let us run the script and read the results. First the poles. For zeta equal to 0, plus or minus j 5. For 0.3, minus 1.5 plus or minus j 4.77. For 0.6, minus 3 plus or minus j 4. For zeta equal to 1, a repeated pole at minus 5. And for zeta equal to 2, two real poles: minus 1.34 and minus 18.66. See how the poles move from the imaginary axis to the real axis as damping increases.

Now stepinfo for zeta equal to 0.6. The peak time is 0.785 seconds, which equals pi by 4, exactly as we calculated in class. The overshoot is 9.48 percent, again identical to the formula. These two match perfectly.

Two values differ slightly, and you must understand why. MATLAB reports the rise time as the time from 10 percent to 90 percent of the final value, which is 0.371 seconds. Our class formula gives the time to reach 100 percent for the first time, which is 0.554 seconds. Both are valid, just defined differently. Similarly, MATLAB measures the settling time as the last time the response leaves the 2 percent band, which is 1.19 seconds, while 4 by zeta omega n gives 1.33 seconds, an approximation. Always state the definition in your lab record.

On the combined plot, the undamped curve oscillates forever between 0 and 2. The curve for 0.3 overshoots heavily. At 0.6 the overshoot is modest. At critical damping the response is the fastest without overshoot, and at zeta equal to 2 it is slow, creeping to the final value.

[6:30] COMMON LAB MISTAKES AND VIVA TIPS
Before leaving the lab, four points. One: the denominator vector must be in descending powers of s: one, two zeta omega n, omega n squared. A wrong order gives a completely different system. Two: if your code uses arrays inside expressions, use the dot operators. Three: write the rise-time definition in your record, as we discussed.

Four: label your axes, add a legend and a title. Marks are given for a clear plot. And for the viva, be ready to answer: what happens to the poles as zeta increases? How does the overshoot change? Why does a critically damped response have no overshoot? You now have all the answers.
