## Description (copy-paste)
Learn how to handle missing values in Python, from theory to a hands-on lab with 49,195 real NYC Airbnb listings.

You will learn:
- Why data goes missing: MCAR, MAR and MNAR
- How to prove the mechanism with a crosstab, instead of guessing
- How to find disguised missing values (0, 999, "Nan")
- Four imputation methods: mean, median, KNN and regression
- How to compare them by checking how much variance each one keeps

Tools: Python, Pandas, scikit-learn (KNNImputer, LinearRegression)
