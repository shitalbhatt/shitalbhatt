Let me add a way to remember the sequence. Audit, diagnose, fix, validate. For diagnosing, remember the four questions: is it true, is it there, is it the same everywhere, is it allowed. For integration, remember key, schema, conflict, audit. For duplicates, remember exact, same key and near. And the strongest lesson of this part: the order of cleaning steps matters, so audit again after every fix, as we saw when lowercase labels hid three hundred copies.
#2
Let me add the key points on missing data. MCAR means the missingness is unrelated to anything. MAR means it is related to other observed columns, such as no reviews meaning no review date. MNAR means it depends on the missing value itself, for example people with high incomes not reporting income. The method follows the mechanism. Every imputation shrinks the variance, so compare methods by how much of the original spread they keep, and never fill with the mean without checking the reason.
#3
Let me add a rule of thumb for each part. First ask why: is the outlier a mistake, a rare real value, a limit, or a different group? Use interquartile range on long-tailed data, and Z-score on bell-shaped data. Use models for odd combinations. Then fix by cause, and compare before and after, using skew and a model score, as in the lab where R squared moved from point one two to point four four. Remember also that removing rows is the only fix that loses data, so use it sparingly.
#4
Let me add the rules for encoding. Nominal means one-hot, ordinal means your own order, and the baseline is the dropped column. Many categories mean frequency or target encoding, and target encoding must use training rows only and smoothing for small groups. For a rare class, accuracy is misleading, so stratify, weight classes, and report recall. The lab showed shared-room recall going from nine point five to sixty-five percent, with a fall in accuracy that was well worth it.

#6
Let me explain the first two answers further. For missing review rates, the proof is a crosstab of missing against zero reviews, with no cases outside the diagonal, which shows the gap is fully explained by an observed column, so it is MAR, and structurally a zero. For Z-score, remember the ruler that stretches: outliers inflate the standard deviation, so the cut-off moves out and the outliers hide behind it. Median-based rules and the interquartile range do not have this problem.
#7
Let me explain the remaining answers further. After title-casing, the lowercase labels become identical to the proper-case rows, so new exact duplicates appear, and the lesson is to audit after each fix. When class weights lower accuracy but raise recall, the model is paying more attention to the rare class, which is usually what we want. And target encoding with the full dataset would let the encoding see the test answers, so the test score would be too good. Always compute encodings from the training rows only.
