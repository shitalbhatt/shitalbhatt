Let me explain the last point about dates. If the order date stays as text, sorting and grouping by month will be alphabetical or fail. With pd dot to datetime, pandas understands the dates, and you can extract the month with dt dot to period. If the date format is day first, which is common in India, pass dayfirst equal to True, otherwise pandas may swap day and month. After converting, check df dot dtypes to confirm. Also, squarify, networkx and wordcloud may need installing with pip.
#2
Let me say what the layers look like in seaborn. You call sns dot barplot, and inside you pass the data, then x, y and hue, which are the aesthetics. The function itself is the geometry. Then you call plt dot title, plt dot xlabel and plt dot ylabel for labels, and sns dot set theme for the theme. Seaborn objects, a newer interface, makes the grammar even more explicit, with a plot object and add calls, so it is worth exploring once you are comfortable with this version.

#4
Let me explain the details. A facet grid in seaborn is made with sns dot catplot, which takes kind equals bar, col equals region, and col wrap equals two. The height and aspect arguments control the size of each small panel. All panels share the same y axis by default, which is what you want for comparison. If you ever turn off the shared axes with sharey equals False, you must say so, because otherwise people will compare panels on different scales without noticing.
#5
Let me explain why this matters beyond one chart. Whenever you create a bar chart of a quantity, ask what the axis baseline is. Libraries may choose a baseline automatically, and some tools do not start at zero. In seaborn and matplotlib bar charts start at zero by default, so the distortion only appears if you set the limits manually with set ylim. It is a deliberate choice, and an examiner or a reader will notice it immediately, so be careful.

Let me explain how to make the honest chart in code. Use two subplots side by side, with plt dot subplots of one row and two columns. On the left, call set ylim with a bottom of point one oh. On the right, leave the axis at its default zero baseline. Give both the same data and the same titles, except that the left one is labelled as a truncated axis for demonstration. In your own work, only draw the honest one, and use this comparison as a reminder.
#7
Let me explain the sorting step. Use the order argument of sns dot countplot or barplot, with a list of categories sorted by value, which you get from value counts dot index. Use horizontal bars by passing y instead of x, so the sub-category names do not overlap. A sorted chart is easier to read than an alphabetical one, because the eye sees the ranking at once, and because the top and bottom are immediately visible, you can write a sentence about them.
#8
Let me explain how to build the treemap. First group the data, for example df dot groupby of category, dot sum of sales. Then pass the values and the labels to squarify dot plot, along with a list of colours and a little alpha for softness. Turn off the axes with plt dot axis of off. If you want a hierarchy with sub-categories inside each category, plotly express has a treemap function that supports nested levels and also lets you click to zoom in an interactive version.
#9
Let me explain the steps. Combine the product names with a space between them, using the join function. Create a WordCloud object with a width, a height and a background colour, and call generate with the text. Show it with plt dot imshow and turn off the axes. Before generating, remove common words with the stopwords parameter, otherwise words like the and for will dominate. If the cloud is not very informative, switch to a bar chart of the top twenty words, which is almost always clearer.
#10
Let me explain how it is built. Start with a graph from networkx. For each pair of customer and sub-category from the data, add an edge. Use the bipartite layout or a spring layout to place nodes, and colour customers and sub-categories differently. Nodes with many edges are popular sub-categories. With only fifteen customers, the picture remains readable, but with thousands of nodes, a network becomes a hairball, so always filter to the most important ones first.
#11
Let me explain gridspec carefully, because it is a new idea. You create a figure with plt dot figure and a size. Then you create a GridSpec of three rows and three columns, with height ratios such as one, two and two. The first row panels, each one column wide, hold the K P I cards. The second row has one panel that spans two columns for the trend, and one for the mix. In each panel, you remove the axes for the cards and write the number in large text. Finally, call tight layout to avoid overlaps. This is the same logic as the dashboard slide in the lecture, now in code.
#12
Let me explain how to colour one bar. First make a list of colours using a list comprehension, such as a strong colour if the region equals Central and grey otherwise. Pass this list as the palette to the bar plot. Then write the title as a sentence with the insight. Finally, remove the top and right spines using sns dot despine, because they carry no information. The result looks professional, and takes only a few lines. This is a pattern you should use in your assignment.
#13
Let me explain how to do it. Group by month to get monthly profit, find the index of the minimum with idx min, and get the corresponding value. Then call ax dot annotate with the text, the xy coordinates of the point, the position of the text, and an arrow style in arrowprops. Choose the text position away from the line so it does not overlap. The advantage of finding the point with code is that if the data changes, the annotation moves with it, and you never have a wrong label.
