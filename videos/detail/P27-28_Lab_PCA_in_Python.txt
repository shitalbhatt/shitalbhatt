The breast cancer data has thirty features and a known diagnosis, so it shows how PCA helps a medical dataset. Both are available in scikit-learn or from the UCI repository, so you can load them without downloading anything complicated. Create a StandardScaler, call fit transform, and wrap the result in a data frame with the same column names. Check with describe that the means are close to zero and the standard deviations equal one. It is worth printing the raw standard deviations first, to see the huge difference between sulfur dioxide and density. That small comparison explains better than any theory why scaling is essential for PCA.
#3
Let me explain what the formula means. The VIF values are the diagonal entries of the inverse of the correlation matrix, so np dot linalg dot inv of the correlation matrix gives them in one line. You can also use statsmodels, which fits each regression. A density of fifteen point nine means the other ten features predict density almost perfectly. In the next step, PCA will combine these linked features, so you do not need to drop density. But it is useful to see the VIF first, because it justifies the use of PCA in your report.
#4
Let me explain the code. From sklearn dot decomposition import PCA. Create pca equal to PCA with random state, and call fit transform on the scaled data, which returns an array with one row per wine and one column per component. Put it in a data frame with the names PC one to PC eleven. Then call corr on that data frame and look at the off-diagonal entries, which are all essentially zero. This confirms the main property of PCA, that the new features are uncorrelated.
#5
Let me explain the attributes. pca dot explained variance underscore gives the eigenvalues, and pca dot explained variance ratio underscore gives the fractions. Since we scaled the data, the eigenvalues add up to eleven, the number of features. An eigenvalue of three point oh three means this component carries as much variance as three original features. The cumulative sum of the ratios is computed with np dot cumsum. Put them in a table with a row for each component, and keep it for your report.
#6
Let me explain how to draw them. For the scree plot, use plt dot bar for the individual percentages and plt dot plot for the cumulative line, on the same axes. Add a horizontal line at ninety percent with axhline, and mark the elbow. The scree plot tells you where the benefit of adding components drops. In this data the bars fall quickly for the first three and slowly afterwards, which is the elbow. The cumulative plot tells you how much information you keep at each choice.
#7
Let me explain how to apply each rule in code. For Kaiser, count the eigenvalues greater than one with np dot sum. For the cumulative rule, pass a number between zero and one to PCA, such as n components equal to point nine, and PCA chooses the smallest number that reaches ninety percent. Then print pca dot n components underscore. Decide with the purpose in mind. If the aim is to draw a picture, take two. If the aim is to feed a model, use ninety percent and compare the model score with all the original features.
#8
Let me explain how to draw it. Make a data frame of loadings with pca dot components underscore transposed, so that rows are features and columns are components. Use sns dot heatmap with a diverging colour map centred at zero and annot equal to True. Look down each column for the strongest red and the strongest blue cells, and write the interpretation in one line. A tip: if all the loadings of one component have the same sign, that component is a general size or level factor, rather than a contrast.
#9
Let me explain how to plot it. Make a scatterplot of the PC one column against the PC two column, with hue equal to the wine type. You will see two overlapping clouds, red on the left and white on the right, with some mixing in the middle. The mean of each type on PC one confirms the numbers on the slide. Keep in mind that PCA did not use the label, so the separation is a bonus. If you coloured by quality instead, you would see little separation, which tells you quality is not captured by the first two components.
#10
Let me explain how to draw the arrows. Use plt dot quiver or plt dot arrow, starting each arrow at the origin and ending at the loading on PC one and PC two, scaled up for visibility. Add the feature name as text at the tip of each arrow. Arrows that point in the same direction belong to features that rise together. The two sulfur dioxide features are very close, as expected. And density and alcohol point in opposite directions, which is why wines with more alcohol are lighter.
#11
Let me explain what this shows. The breast cancer data has measurements of cell nuclei, such as radius, perimeter and area. These are strongly linked, since a bigger cell has a bigger perimeter and area. That is why the variance inflation factor of mean radius is in the thousands. PCA handles this beautifully: thirty linked features collapse into a few components. The first component stands for overall size and irregularity, and the malignant cells score high on it. Two numbers are enough to see the two diagnoses form two groups.
