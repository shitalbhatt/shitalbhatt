#6
Let me explain the first two answers further. A log transform has one fixed strength, so on a feature that is already symmetric it pulls the large values in too much and makes a left skew. The better options are to leave it alone, or to use Box-Cox, which finds a power close to one for such a feature. For min-max, the cause is the maximum, which is set by a single extreme row. Applying a transform first, to shrink the tail, or using the robust scaler, which uses the median and interquartile range, avoids it.
#7
Let me explain the remaining answers further. Feature selection must use training rows only because any use of the test labels, even indirectly through the choice of features, makes the test score optimistic. A recall of point nine nine after over-sampling is a warning, because it is often leakage from copies. And t-SNE is not used as model input because it has no transformation for new data, its picture changes with the seed and settings, and its distances are not meaningful. For a model, use PCA or LDA inside a pipeline.
