#2
Let me repeat why we use only four features. Sales, quantity, discount and profit are numeric measurements that describe an order. Postal code is a label, so it is dropped. Keeping the feature list in one variable, say features, and reusing it in every step, is a good habit, because if you change the list once, every later step follows. It also prevents the very common mistake of scaling one set of columns and clustering another.
#3
Let me explain how to interpret this. Pairwise correlations tell us whether two features are close to copies. Since no cell is near plus or minus one, no pair is redundant. However, remember the lecture: a feature could still be predicted from a combination of several others even if every pair is weak. That is why we do the second step, the V I F, which looks at all the other features together, rather than only pairs.
#4
Let me explain the idiom. You build a list by calling variance inflation factor on the scaled or raw feature matrix, passing the matrix values and the column position, for each position in a range. Then you put the results in a small data frame with the feature names, so that you can read them. For a model with an intercept, you may add a constant column before computing, as the statsmodels documentation recommends. A value near one, such as one point oh four, means almost no overlap with the other features, so we keep all four.
#5
Let me explain what fit transform does. Fit learns the mean and standard deviation of each column. Transform subtracts the mean and divides by the standard deviation. Doing both in one call is convenient for exploring. Later, when you build predictive models, you will fit the scaler only on the training data and only transform the test data, to avoid leakage. After scaling, check with scaled dot mean and scaled dot std that the means are near zero and the standard deviations near one, which is a good sanity check.
#6
Let me explain each setting. The number of clusters is three, which we chose in the lecture. Random state fixes the random starting positions, so that you and I get the same answer. N init of ten means the algorithm starts ten times and keeps the one with the lowest within-cluster distance. After fitting, add the labels to your original, unscaled data frame as a new column, so that you can interpret clusters in real units such as dollars. Count the group sizes with value counts to see how balanced the clusters are.
#7
Let me explain how to read the scores. The silhouette score is the average over all points of how well each fits its own cluster compared with the nearest other cluster. A score above zero point five suggests a reasonable structure, between zero point two five and zero point five suggests weak structure, and below that means little structure. Here the scores for two to six clusters are around zero point four to zero point five, a moderate structure. Notice the slight bump at five, where the score rises from zero point four three one to zero point four three seven, so the curve is not perfectly smooth.

Let me explain the interpretation step. df dot groupby of cluster dot mean gives the average sales, quantity, discount and profit for each group in dollars and units, which is far more meaningful than the scaled numbers. Let me explain what this tells us. A variance inflation factor near one for all of age, fare and family counts means that these Titanic features are not redundant.
