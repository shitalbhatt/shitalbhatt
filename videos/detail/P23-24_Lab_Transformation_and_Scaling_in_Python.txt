Let me explain why the missing values are filled first. Transformers such as Box-Cox and StandardScaler do not accept missing values, and np dot log one p returns NaN for them, which then spreads through your calculations. Because total bedrooms is skewed, the median is a better fill than the mean. Using df dot fillna with the median is one line. In a proper model pipeline, you would compute the median from the training rows only, but for exploring the effect of transforms, using the full data is fine.

#3
Let me explain the over-correction. Population had a skew of nearly five. A log of one plus x pulls the large values in strongly, and it overshoots, so the distribution now has a long tail on the left, with a skew of about minus one. That is still better than five in absolute terms, but it is not the symmetric result we wanted. For median income, which had a moderate skew, log works nicely. This shows that a single transformation is not ideal for all features, which is why we try Box-Cox, where each feature gets its own lambda.

#11
Let me explain how to read the box plots. The aim of scaling is that features become comparable. After standard scaling, the box plots are centred on zero, but count features still have whiskers and dots reaching fifteen or thirty, because the outliers remain far away. After min-max, those count features are squeezed into a thin box near zero. After robust scaling, every box has the same height and the same median, so you can compare them directly, though the outliers remain visible as dots.
#12
Let me explain the trap in detail. The largest block group has about thirty-five thousand people, and the typical one has eleven hundred sixty-six. Min-max scaling sets the largest to one, so the typical one becomes about zero point oh three. Ninety-six percent of the values are below zero point one, so a model sees almost no difference between most of the districts. The ranges are zero to one, but nearly all the information is packed into a tiny part of that range. Transform first, so that the extreme value is no longer so far from the rest, or use the robust scaler.
#13
Let me explain how to use the one-step version. PowerTransformer with method box-cox and standardize equal to True first applies Box-Cox to each feature and then standard scales it. The result has mean zero, standard deviation one, and almost no skew. For modelling, put it inside a pipeline, so that the lambdas and the scaling parameters are learned from the training data only. Calling fit on the full data before splitting is a form of leakage, because the test rows influence the transformation. We will build such a pipeline in practical twenty-nine.
