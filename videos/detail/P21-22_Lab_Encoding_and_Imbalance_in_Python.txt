Let me explain the weights formula with the numbers. With forty-eight thousand eight hundred eighty-four rows and three classes, the weight for a class is rows divided by three times the class count. For shared rooms, with about twelve hundred homes, that gives about fourteen, while for entire homes it is about zero point six. So each shared room is treated as worth about twenty-two entire homes. scikit-learn computes this for you with class weight equal to balanced, or with the compute class weight function, if you want to see the numbers.
