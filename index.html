Module 1 · L1–6 · P1–6

Statistical & data foundations

L1–2 · Role of EDA, sampling, summary statistics

EDA vs confirmatory

ExploratoryConfirmatory
QuestionWhat is going on?Is this claim supported?
HypothesisGenerated by analysisFixed before seeing data
LooksUnlimitedOne, pre-specified
OutputHypotheses, clean datap-values, CIs

Never test a hypothesis on the same rows that suggested it. Split first, explore on one part, confirm once on the held-out part.

Five jobs of EDA

  1. Sanity: does the file match its documentation?
  2. Quality: missing, duplicates, impossible values, sentinels (0, −1, 999)
  3. Structure: shapes, relationships, clusters, trends
  4. Hypotheses worth testing later
  5. Modelling decisions: transforms, features, baselines

Pima diabetes: describe() shows Glucose, BloodPressure, BMI = 0, which are missing values encoded as zero.

Sampling and bias

Target population → sampling frame → sample → estimate. Coverage error is the gap between population and frame. Write: “This sample can support claims about ___, and cannot support claims about ___.”

Selection biasSelf-selectionSurvivorship (Wald’s bombers)Non-responseUndercoverage (1936 Literary Digest)Measurement bias

Bias vs variance. Bias is systematic error, does not shrink with more data. Variance is random error, shrinks about 1/√n. A big biased sample is more dangerous than a small random one. Model error = Bias² + Variance + Irreducible noise.

Shape and summary statistics

IdeaRule
Right skewmode < median < mean; tail names the skew, not the hump
Left skewmean < median < mode
Excess kurtosis= kurtosis − 3. >0 heavy tails (leptokurtic), ≈0 mesokurtic, <0 light tails (platykurtic). Measures tails, not peak sharpness
IQR fenceQ1 − 1.5·IQR … Q3 + 1.5·IQR
Which to reportSymmetric → mean + SD. Skewed → median + IQR. Always put a plot next to the number

Three reasons a point is far out: a mistake (fix/remove), rare but real (keep), wrong population (separate). A flag is a question, not a verdict. The |z|>3 rule cannot fire on small samples: ceiling is (n−1)/√n.

L3–4 · Data types and structures

Scales of measurement

ScaleExampleAllowed
Nominalblood type, countrymode, counts
Ordinalsatisfaction, education+ median, rank
Interval°C, year, IQ+ mean, no ratios
Ratioincome, weight, ageall, incl. ratios

Discrete = counted (visits, defects). Continuous = measured (height, time).

Structure and text

Structured: fixed schema, tables. Semi-structured: tags, varying fields (JSON, XML, emails).

Text pipeline: corpus → document → token → term/vocabulary. Prep: lowercase, remove stopwords, stem/lemmatise → term-frequency table.

Time series: trend (long-term direction) + seasonality (fixed-interval repeating pattern). Separate them before concluding.

L5–6 · Images, audio, dimensionality, ethics

Everything is numbers

  • Image: (height, width) grid, 0–255. Colour adds a third axis: 1024×1024×3 = 3,145,728 numbers
  • Audio: amplitudes sampled over time. 16 kHz × 10 s = 160,000 numbers
  • Image EDA starts with the pixel intensity histogram (spikes at 0/255 = clipped)

Curse of dimensionality

10 points per axis needs 10d points. Data becomes sparse, distances concentrate (nearest ≈ farthest), data hugs the edges, models overfit, plots stop working.

Fixes: feature selection, PCA, regularisation, more relevant data.

Bias and ethics

Bias enters at the world → collection → labelling → modelling → deployment, and deployment feeds back into collection. Ask: Consent, Privacy, Fairness, Consequence. Split every summary by group, check missingness by group, count rows per group, document exclusions, say what the data cannot answer.

L9–10 · Bivariate: correlation, covariance, cross-tabs

Numerical–numerical

Cov(X,Y) = Σ(xᵢ − x̄)(yᵢ − ȳ) / (n−1)

r = Cov(X,Y) / (σₓ σᵧ) ∈ [−1, 1]

Covariance gives direction in awkward units. Correlation is scale-free. Spearman ρ ranks first: catches monotonic, outlier-robust. Superstore Discount vs Profit: Pearson −0.22, Spearman −0.54.

Correlation ≠ causation. Always pair r with a scatterplot.

Cross-tab: similar row % across rows → independent-looking; differing row % → associated (chi-square later).

K-means (exploratory only)

  1. Choose k
  2. Place k centres
  3. Assign each point to nearest centre
  4. Move centres to group means
  5. Repeat until stable

L13–14 · Grammar of graphics, storytelling (Assignment 1)

Grammar of Graphics: data → aesthetic mappings (x, y, colour, size) → geometry (points, bars, lines) → scales → facets → theme. A good plot answers one question and encodes it with the most accurately perceived channel (position > length > area > colour).

Misleading plots: truncated axes, 3-D pies, dual axes, too many slices, colour with no meaning, hidden outliers via scale.

Dashboard logic: 2–3 charts, each tied to a question (e.g. “where do we lose money?” → profit by category; “why?” → discount vs profit; “who?” → segment cross-tab).

L15–16 · Data quality, integration, validation

Four dimensions

  • Accuracy: correct vs reality (compare to peer median). A $10,000 private room passes validity but fails accuracy
  • Completeness: how much and why missing
  • Consistency: one fact, one spelling (10 borough labels for 5 boroughs)
  • Validity: range / set / format / type / uniqueness rules

Integration steps

  1. Match key
  2. Align schema (rename price_usd → price)
  3. Resolve conflicts (case-only → keep source A)
  4. Re-audit

Standardising labels created 300 new exact duplicates. Re-audit after every fix.

Lab numbers (NYC Airbnb merge)

49,895 × 17 → 48,895 × 16. 700 duplicate rows, 1 duplicate column (price_usd), 20,573 missing cells, 11 listings at $0, 66 priced >20× peer median. log1p on price: skew 19.12 → 0.55. Then StandardScaler (log first, scale second; do not scale ids or coordinates).

L17–18 · Missing values

MCAR

Missing by pure chance, unrelated to anything. Can never be proven, only “consistent with” (Little’s test).

MAR

Depends on another observed column. Airbnb: all 10,116 missing reviews_per_month rows have number_of_reviews = 0.

MNAR

Depends on the missing value itself (high earners hide income). Untestable from data; needs domain knowledge.

Imputation compared (reviews_per_month, observed variance 2.824)

Every imputation shrinks variance. Detect with isnull().sum(), missingness matrix, and a crosstab against an observed column.

L19–20 · Outliers

Causes and types

Causes: entry error, genuine extreme, measurement cap (California 500,001), different population (host with 327 listings).

Types: global, contextual (check per group), collective, multivariate.

Detection

Z-score |z|>3 (bell-shaped only). Price limit mean+3σ = $873. Masking: outliers inflate σ and hide themselves.

IQR fences: price Q1 69, Q3 175 → upper $334, flags 2,972 (≈8× Z-score).

Models: Isolation Forest, LOF, DBSCAN (−1 = outlier). Many columns at once.

L23–24 · Transformation and scaling (California Housing)

Transform vs scale

TransformScale
Changesthe shape (non-linear)the units (linear)
Skew / kurtosischangestay exactly the same
Exampleslog, sqrt, Box-Cox, Yeo-JohnsonStandard, MinMax, Robust

Skewed data: transform first, then scale. |skew| < 0.5 symmetric, 0.5–1 moderate, > 1 strong.

Why transform

  1. Squashed plots: the tail stretches the axis
  2. Model assumptions: regression, LDA prefer symmetric features
  3. False outliers: long-tail values are normal there
  4. Mixed units: big numbers dominate distances and gradients (this one needs scaling)

Log and Box-Cox

log1p: y = log(1 + x), x ≥ 0

Box-Cox: y = (x^λ − 1)/λ, λ ≠ 0; log(x) if λ = 0

Box-Cox picks λ by maximum likelihood and needs x > 0; use Yeo-Johnson for zeros or negatives. Ladder: λ=1 none, 0.5 √, 0 log, −1 reciprocal.

Three scalers

ScalerFormulaOutliers
Standard(x − mean)/stdstay far, pull mean/std
MinMax(x − min)/(max − min)one extreme squeezes the rest
Robust(x − median)/IQRignored, best with outliers

  • median_house_value outliers: 1,071 → 16 after Box-Cox. Population kurtosis 73.6 → 2.0.
  • Scaling never changes skew (population stays 4.94). MinMax trap: 96% of population falls below 0.10 because one block group has 35,682 people.
  • 207 missing total_bedrooms are filled with the median first, since transformers cannot take NaN. median_house_value is top-coded at 500,001.

Which method: heavy skew, x > 0 → Box-Cox. Simple, x ≥ 0 → log1p. Zeros/negatives → Yeo-Johnson. Already symmetric → leave alone. PCA/regression/SVM → Standard. Heavy tails → Robust. Tree models → usually none. For models, fit on train only, then transform test.

L25–26 · Feature engineering and selection (Online Shoppers)

Construct

12,330 sessions, target Revenue. Same logistic regression, test ROC-AUC: 0.855 (10 original) → 0.898 (+8 constructed) → 0.904 (+3 interactions). Only the features changed.

RecipeIdeaExample

Start from domain knowledge. Never build from the target (leakage). Guard divisions by zero. Test each feature: same model, same split, before vs after.

Interactions

y = b₀ + b₁A + b₂B + b₃(A×B)

If b₃ ≠ 0 the slope of A depends on B. Detect with a two-way table: page value lifts new visitors 7% → 86% but returning visitors only 3% → 51%. Unequal jumps = interaction.

Polynomial features

columns = C(n + d, d) − 1

PolynomialFeatures(degree=2). 3 inputs → 9 columns. Scale first, keep degree low, pair with selection or L1. At degree 3 the 85 encoded features would give 109,735 columns for 12,330 rows.

Curse of dimensionality (this dataset)

  • 4 bins per feature: with 10 features only 0.2% of cells hold any session
  • Logistic regression on 400 sessions: train AUC rises to 0.996 while test AUC falls 0.878 → 0.743 (285 columns)
  • Fixes: more data, feature selection, regularisation, dimensionality reduction, domain knowledge. Rule of thumb: ≥ 10 cases of the rarer class per feature (Pima: 268 positives → about 27 features)

L27–28 · Dimensionality reduction (Wine Quality)

VIF

VIF = 1 / (1 − R²)

Wine (6,497 wines, 11 measurements): density 15.9, residual_sugar 7.2, fixed_acidity 4.9, alcohol 4.8. > 10 is serious. Drop density and the largest VIF falls to 2.8. PCA components always have VIF = 1.

PCA

Rotates to uncorrelated axes: PC1 = most spread, PC2 next at 90°. Does not use the target. Scale first: unscaled, total sulfur dioxide (std 8057) makes PC1 = 95.4% from units alone.

PC1 + PC2 = 50% of 11 features. Keep 3 by elbow or Kaiser (eigenvalue > 1); 7 for 90%.

t-SNE and UMAP

Pictures only. Axes meaningless, gaps and sizes unreliable, change with seed and settings, t-SNE cannot place new rows. Never feed a model with t-SNE.

Goal → method: linked features → VIF; compress → PCA; separate classes → LDA; look at clusters → t-SNE/UMAP.
