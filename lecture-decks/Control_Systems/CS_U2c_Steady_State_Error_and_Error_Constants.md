| 3 | Recap: What You Already Know | • Unity feedback: error e = r − c.<br>• Closed-loop stable systems have a final value.<br>• Final value theorem: lim s·F(s) as s → 0.<br>• Test signals: 1/s, 1/s², 1/s³.<br>**Formula/Key:** lim t→∞ f(t) = lim s→0 s·F(s)   (poles in left half-plane only) | Unity feedback loop with E(s) and the error formula derived on it. | Recall the final value theorem: the steady value of a time function is the limit of s times its transform as s goes to zero. It is valid only if all poles of s F of s are in the left half-plane. We apply it to the error signal of a unity-feedback system. The result depends on the open-loop transfer function and on the input signal. |
| 4 | Motivation: Tracking Accuracy | • A radar must follow a moving aircraft.<br>• A robot must follow a path precisely.<br>• Transient dies out but a constant gap may remain.<br>• Steady-state error measures that final gap.<br>**Formula/Key:** Design aim: keep ess within the allowed limit for the expected input | Ramp target with the output lagging behind by a constant gap marked as the steady-state error. | A tracking antenna follows a satellite moving at constant angular speed, which is a ramp input. | 5 | Steady-State Error | • Error: e(t) = r(t) − c(t) (unity feedback).<br>• E(s) = R(s)/(1 + G(s)).<br>• Apply the final value theorem to E(s).<br>• The result depends on G(s) at s → 0.<br>• Valid only for a stable closed loop.<br>**Formula/Key:** ess = lim s→0 s·R(s)/(1 + G(s))<br>G(s) open-loop transfer function, R(s) input | Unity-feedback diagram and the derivation steps written below. | From the block diagram E equals R minus C and C equals G times E, so E equals R over one plus G. Multiply by s and take the limit. Always check the stability of the closed loop first, otherwise the error does not settle. For non-unity feedback, first convert the system to an equivalent unity-feedback form. |
| 6 | Type of a System | • Type = number of poles of G(s) at s = 0.<br>• Type 0: no integrator.<br>• Type 1: one integrator.<br>• Type 2: two integrators.<br>• Type tells which inputs are tracked with zero error.<br>**Formula/Key:** G(s) = K ∏(τᵢ s + 1) / [sᴺ ∏(τⱼ s + 1)];   type = N | Three cards: Type 0, 1, 2 with example G(s) and the origin poles drawn on the s-plane. | The type of the system is the power of s in the denominator when G of s is written in the time-constant form. Each integrator at the origin improves the tracking ability by one step. Note that type is a property of the open-loop transfer function, not the closed loop. Count the poles at the origin carefully before using the error constants. |
| 7 | Static Position Error Constant Kp | • Input: unit step, R(s) = 1/s.<br>• Kp = lim G(s) as s → 0.<br>• Type 0: Kp = K, finite error.<br>• Type 1 or higher: Kp = ∞, zero error.<br>**Formula/Key:** ess = 1/(1 + Kp) for a unit step;   A/(1 + Kp) for amplitude A<br>Kp = lim s→0 G(s) | Unit step input and output of a Type 0 system, with the constant gap labelled. | For a step input, R of s is A over s, and the error reduces to A over one plus G of zero. G of zero is the position error constant Kp. A type 0 system has a finite Kp, so it leaves a constant error. A type 1 system has an integrator, Kp is infinite and the step error is zero. |
| 8 | Static Velocity Error Constant Kv | • Input: unit ramp, R(s) = 1/s².<br>• Kv = lim s·G(s) as s → 0.<br>• Type 0: ess = ∞.<br>• Type 1: finite error 1/Kv.<br>• Type 2 or higher: zero error.<br>**Formula/Key:** ess = A/Kv for a ramp of slope A<br>Kv = lim s→0 s·G(s) | Ramp input and output of a Type 1 system with the constant lag marked. | For the ramp, E of s becomes A over s squared times one plus G, and the limit gives A over the limit of s G of s. That limit is Kv. A type 1 system tracks a ramp with a constant lag of A over Kv. Increasing the gain raises Kv and reduces the error, but it also affects stability, which is the central trade-off in design. |
| 9 | Static Acceleration Error Constant Ka | • Input: parabola A·t²/2, R(s) = A/s³.<br>• Ka = lim s²·G(s) as s → 0.<br>• Types 0 and 1: infinite error.<br>• Type 2: finite error A/Ka.<br>• Type 3 or higher: zero error.<br>**Formula/Key:** ess = A/Ka;   Ka = lim s→0 s²·G(s) | Parabolic input and output of a Type 2 system with constant gap A/Ka. | The parabola represents constant acceleration. Only a type 2 or higher system can follow it with a finite error. The acceleration error constant is the limit of s squared times G of s. This is important for satellite tracking systems where the target accelerates. Remember that the size of A is the coefficient of t squared over two. |
| 10 | Error Table: Type vs Input | • Higher type → better tracking, but harder stability.<br>• Zero error needs enough integrators.<br>• Finite errors use Kp, Kv or Ka.<br>• Superposition applies for combined inputs.<br>**Formula/Key:** r = A·u(t) + B·t + (C/2)·t²  →  ess = A/(1+Kp) + B/Kv + C/Ka | 3×3 table with types as rows and step/ramp/parabola as columns; constants listed below. | This table is the most important result of the lecture. Memorise the pattern: the diagonal gives finite errors, above the diagonal gives zero and below it gives infinite error. For a mixed input, apply superposition and add the individual errors. An infinite term in the sum makes the total error infinite. |
| 11 | Generalized Error Series | • Static constants cover only step, ramp, parabola.<br>• Series handles any smooth input r(t).<br>• Expand 1/(1 + G(s)) in powers of s.<br>• Coefficients Cn are dynamic error coefficients.<br>• Error follows from the derivatives of r(t).<br>**Formula/Key:** e(t) = C0·r(t) + C1·r′(t) + (C2/2!)·r″(t) + …<br>Cn = dⁿ/dsⁿ [1/(1 + G(s))] at s = 0 | Four-step vertical flow: E(s) → series in s → time-domain error → coefficient definition. | Write E of s as one over one plus G times R of s and expand one over one plus G in a power series in s. Each power of s corresponds to a derivative in time. The coefficients are found by long division in ascending powers of s. The series is useful for a time-varying error, and the first non-zero term dominates the steady state. |
| 12 | Solved Example 1: Static Constants | • Unity feedback, G(s) = 20(s + 2)/[s(s + 4)(s + 5)]. Input r = 6t. Find type, Kp, Kv, Ka, ess.<br>• 1. Stability: s³ + 9s² + 40s + 40 → all Routh entries positive: stable.<br>• 2. One pole at origin: Type 1.<br>• 3. Kp = ∞.<br>• 4. Kv = lim sG = 20×2/(4×5) = 2.<br>• 5. Ka = lim s²G = 0.<br>• 6. Ramp slope A = 6: ess = A/Kv = 3.<br>**Formula/Key:** Answer: Type 1, Kp = ∞, Kv = 2, Ka = 0, ess = 3 for r = 6t | Left: steps; right: ramp input and parallel output with the constant error 3 marked. | First confirm stability with the characteristic equation, otherwise the final value theorem cannot be used. The system has one pole at the origin, so it is type 1. The limit of s G of s is twenty times two over four times five, which is 2. The input is 6 t so the slope is 6 and the error is 6 over 2, equal to 3. |
| 13 | Solved Example 2: Error Series | • Unity feedback, G(s) = 10(s + 1)/s². Input r(t) = 3t². Find ess by Ka and by the error series.<br>• 1.
