| 5 | Proportional (P) Controller | • Output proportional to the error.<br>• Raising Kp speeds up the response.<br>• Too large Kp gives overshoot and oscillation.<br>• A steady-state offset remains for Type 0 plants.<br>**Formula/Key:** u(t) = Kp·e(t);   Gc(s) = Kp<br>ess(step) = 1/(1 + Kp·G(0)) for a Type 0 plant | Step responses for Kp = 1, 4 and 12 showing faster response but a persistent offset. | The proportional controller multiplies the error by a constant. A larger gain reduces the offset and speeds up the response, but never removes the offset for a Type 0 plant. If the gain is too large the response oscillates and may become unstable. That is why we need the integral and derivative terms. |
| 6 | Proportional–Integral (PI) Controller | • Integral term accumulates the error.<br>• Output keeps changing until the error is zero.<br>• Eliminates the steady-state error.<br>• Adds lag: may increase overshoot and slow down.<br>• Pole at origin raises system type by one.<br>**Formula/Key:** u = Kp·e + Ki∫e dt;   Gc(s) = Kp + Ki/s = Kp(1 + 1/(Ti s)),  Ti = Kp/Ki | Step response of P-only against PI: the PI curve settles at exactly 1. | The integral action sums the error over time. As long as any error remains, the control signal continues to change. So the final error must be zero for a step input. The cost is extra phase lag that reduces damping. In practice PI is the standard choice for slow processes such as temperature or level. |
| 7 | Proportional–Derivative (PD) Controller | • Derivative term reacts to the rate of change of error.<br>• Adds damping: reduces overshoot.<br>• Acts like a lead compensator.<br>• Amplifies high-frequency noise.<br>• No effect on steady-state error.<br>**Formula/Key:** u = Kp·e + Kd·de/dt;   Gc(s) = Kp + Kd·s = Kp(1 + Td s),  Td = Kd/Kp | Step response of a lightly damped loop with P control against the same loop with PD control. | The derivative term is a prediction: if the error is falling fast, the controller reduces the drive early so as to avoid overshoot. It behaves like a lead network by adding phase lead. But differentiation amplifies noise, so in real controllers the derivative is filtered. It does nothing for a constant error, so it never fixes the steady-state offset. |
| 8 | PID Controller | • Combines proportional, integral and derivative actions.<br>• P gives speed; I removes offset; D adds damping.<br>• Standard form uses Ti and Td.<br>• Equivalent to a lag–lead compensator.<br>**Formula/Key:** u = Kp[e + (1/Ti)∫e dt + Td·de/dt];   Gc(s) = Kp + Ki/s + Kd·s<br>Ki = Kp/Ti,  Kd = Kp·Td | Step response of P-only (dashed) and PID (solid): fast, no overshoot, zero offset. | The PID controller combines the three actions. The integral action takes care of the steady-state error, the derivative action improves damping and the proportional action provides the main drive. In the standard form the integral and derivative parameters are written as time constants Ti and Td. In the s-domain it is a lag-lead compensator with a pole at the origin. |
| 9 | Effect of Each Gain | • Each term changes the response differently.<br>• Tune one gain at a time, small steps.<br>• Large Ki causes oscillation.<br>• Large Kd amplifies noise.<br>**Formula/Key:** Kp ↓ error, ↑ speed;   Ki → zero error;   Kd ↑ damping | Table of the effect of increasing Kp, Ki and Kd on rise time, overshoot, settling time and steady-state error. | This table is a quick guide when tuning by hand. Increasing Kp makes the system faster but less damped. Increasing Ki removes the steady-state error but can cause oscillation. Increasing Kd gives more damping but also amplifies noise. These are trends, not exact rules, so always confirm by simulation or experiment. |
| 10 | Ziegler–Nichols Tuning | • Set Ki = Kd = 0; raise Kp until steady oscillation.<br>• Record the critical gain Kcr and period Pcr.<br>• Use the table to set Kp, Ti and Td.<br>• Gives a quick, reasonable first tuning.<br>• Fine-tune afterwards.<br>**Formula/Key:** P: Kp = 0.5Kcr;   PI: Kp = 0.45Kcr, Ti = Pcr/1.2<br>PID: Kp = 0.6Kcr, Ti = 0.5Pcr, Td = 0.125Pcr | Sustained oscillation of period Pcr with the critical gain, and the formulas for PID. | The ultimate-gain method of Ziegler and Nichols needs only one experiment. Use proportional control and increase the gain until the output oscillates steadily. The gain at that point is the critical gain and the period of oscillation is the critical period. Simple formulas then give the PID settings. The result is a good starting point, often with about twenty-five per cent overshoot. |
| 11 | Solved Example 1: P vs PI | • Plant G(s) = 1/(s² + 2s + 1), unity feedback. Compare steady-state error for a unit step with P (Kp = 1) and PI (Kp = 1, Ki = 1).<br>• 1. P: ess = 1/(1 + Kp·G(0)) = 1/(1 + 1) = 0.5.<br>• 2. PI: Gc·G has a pole at the origin → Type 1.<br>• 3. Kp(PI) = ∞ so ess = 0.<br>• 4. Check stability: s³ + 2s² + 2s + 1 = 0 → Routh: 2·2 > 1 → stable.<br>**Formula/Key:** Answer: P gives ess = 0.5; PI gives ess = 0 (stable) | Left: steps; right: simulated step responses for P and PI. | For the proportional controller the loop gain at zero frequency is one, so the error is one over one plus one, equal to 0.5. With PI the open loop contains the integrator, so the system is type one and the step error is zero. Always check stability after adding the integrator: the Routh test on the characteristic polynomial confirms stability. The plot confirms both results. |
| 12 | Solved Example 2: Ziegler–Nichols PID | • A P-only test gives sustained oscillation at Kcr = 8 with period Pcr = 2 s. Tune a PID.<br>• 1. Kp = 0.6Kcr = 4.8.<br>• 2.
