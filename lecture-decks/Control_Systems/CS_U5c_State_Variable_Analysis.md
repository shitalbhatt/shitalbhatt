| 4 | Motivation: Beyond the Transfer Function | • Robots and aircraft have many inputs and outputs.<br>• Nonlinear and time-varying systems.<br>• Need to know internal quantities, e.g. current.<br>• Computers solve first-order matrix equations easily.<br>**Formula/Key:** State space = the language of modern control, simulation and estimation | Comparison table of the transfer-function and state-space approaches. | A quadcopter has four motors and many outputs, so a single transfer function is not enough. | 5 | State, State Variables, State Space | • State: the smallest set of variables describing the system.<br>• State variables: x1, x2, …, xn.<br>• State vector x(t): the column of states.<br>• State space: the n-dimensional space of x.<br>• Number of states = order of the system.<br>**Formula/Key:** x(t) = [x1 x2 … xn]ᵀ,  n = number of energy-storage elements | System box with three internal state circles between input u(t) and output y(t). | The state of a system at any time is the minimum information needed to predict its future when the input is known. For physical systems the natural choices are the quantities that store energy, such as capacitor voltage, inductor current, position and velocity. The number of independent states equals the order of the differential equation. |
| 6 | State Equations | • State equation: ẋ = A x + B u.<br>• Output equation: y = C x + D u.<br>• A: system matrix (n × n).<br>• B: input matrix; C: output matrix; D: feedthrough.<br>• SISO: u and y are scalars.<br>**Formula/Key:** ẋ = A x + B u;   y = C x + D u<br>A n×n, B n×1, C 1×n, D 1×1 for a SISO system | Block diagram: u → B → Σ → ∫ → x → C → Σ → y, with A fed back and D as a bypass. | The state equation gives the derivative of every state as a combination of the states and the input. The output equation picks the output from the states. The block diagram shows an integrator per state, a feedback through A, and the paths B, C and D. For most physical systems D is zero. |
| 7 | Physical Variable Approach | • Choose physically meaningful states.<br>• Energy-storage elements give the states.<br>• Write the governing physical laws.<br>• Rearrange into first-order form.<br>• Read off the matrices.<br>**Formula/Key:** Electrical: x = vC, iL;   mechanical: x = position, velocity | Five-step flow chart for forming the state model. | In the physical variable approach we pick states with a physical meaning. For a circuit these are capacitor voltages and inductor currents, for a mechanical system they are the position and velocity of each mass. Write the physical laws, solve each equation for the derivative of a state, and then arrange the coefficients into the matrices. |
| 8 | State Model of a Series RLC Circuit | • States: x1 = vC, x2 = iL = i.<br>• Capacitor: i = C·dvC/dt → ẋ1 = x2/C.<br>• KVL: u = R i + L di/dt + vC.<br>• Solve: ẋ2 = −x1/L − (R/L)x2 + u/L.<br>• Output: y = vC = x1.<br>**Formula/Key:** A = [[0, 1/C], [−1/L, −R/L]],   B = [0, 1/L]ᵀ,   C = [1  0] | Series RLC circuit with x1 = vC and x2 = i marked, and the two state equations beneath. | Choose capacitor voltage and inductor current as states. The capacitor equation gives the derivative of x1 directly. Kirchhoff's voltage law around the loop gives the derivative of the current. Writing the two equations in matrix form gives A, B and C. Notice that A has the circuit elements as entries. |
| 9 | State Model of Mass–Spring–Damper | • States: x1 = x (position), x2 = ẋ (velocity).<br>• ẋ1 = x2 by definition.<br>• Newton: M ẍ = u − B ẋ − K x.<br>• Solve for ẋ2.<br>• Output: y = x = x1.<br>**Formula/Key:** A = [[0, 1], [−K/M, −B/M]],   B = [0, 1/M]ᵀ,   C = [1  0] | Wall–spring–damper–mass sketch with the state equations written below. | For a mass spring damper the natural states are the position and the velocity. The first state equation is just the definition of velocity. Newton's second law gives the second one. The resulting A matrix has the same form as the RLC case: compare K over M with one over L C and B over M with R over L, which is the analogy again. |
| 10 | Advantages of State Space | • Handles MIMO systems naturally.<br>• Works for nonlinear and time-varying systems.<br>• Includes initial conditions.<br>• Gives access to every internal state.<br>• Easy to simulate and design by computer.<br>**Formula/Key:** Transfer function: external description;  state space: internal description | Two-column comparison table (transfer function vs state space). | The transfer function describes only the relation between input and output. The state model includes initial conditions and gives all internal variables, which is needed for state feedback and observers. It also extends to multi-input multi-output, nonlinear and time-varying systems. The price is that we deal with matrices, so we usually use a computer. |
| 11 | From State Model to Transfer Function | • Take the Laplace transform with x(0) = 0.<br>• Solve for X(s).<br>• Substitute into the output equation.<br>• Poles of G(s) are the eigenvalues of A.<br>**Formula/Key:** G(s) = C (sI − A)⁻¹ B + D;   characteristic equation: det(sI − A) = 0 | Four stacked cards showing the derivation of G(s) from the state model. | Transform the state equation with zero initial state and solve for X of s using the inverse of s I minus A. Substitute into the output equation to get G of s. The denominator of G is the determinant of s I minus A, so the closed-form poles are the eigenvalues of A. This provides the link between the two descriptions. |
| 12 | Solved Example 1: RLC State Model | • R = 2 Ω, L = 1 H, C = 0.25 F; output vC. Find A, B, C and G(s).<br>• 1. x1 = vC, x2 = i: ẋ1 = 4x2, ẋ2 = −x1 − 2x2 + u.<br>• 2. A = [[0, 4], [−1, −2]], B = [0, 1]ᵀ, C = [1 0], D = 0.<br>• 3. sI − A = [[s, −4], [1, s + 2]], det = s² + 2s + 4.<br>• 4. (sI − A)⁻¹B = [4, s]ᵀ/det.<br>• 5. G(s) = C(sI − A)⁻¹B = 4/(s² + 2s + 4).<br>**Formula/Key:** Answer: G(s) = 4/(s² + 2s + 4); eigenvalues −1 ± j1.73 | Left: steps; right: the matrices A, B, C and the resulting G(s) and eigenvalues. | Substitute the component values into the general model. Then compute the determinant of s I minus A and the product with B. The first element of the result is the transfer function. It matches the transfer function derived in the first lecture of Unit 1, which confirms that the two descriptions agree. The eigenvalues are the poles. |
| 13 | Solved Example 2: Mass–Spring–Damper | • M = 2 kg, B = 4 N·s/m, K = 8 N/m; output x. Find the state model and G(s).<br>• 1. x1 = x, x2 = ẋ: ẋ1 = x2, ẋ2 = −4x1 − 2x2 + 0.5u.<br>• 2. A = [[0, 1], [−4, −2]], B = [0, 0.5]ᵀ, C = [1 0].<br>• 3. det(sI − A) = s² + 2s + 4.<br>• 4. G(s) = 0.5/(s² + 2s + 4) = 1/(2s² + 4s + 8).<br>• 5.
