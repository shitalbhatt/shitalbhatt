| 3 | Recap: What You Already Know | • Transfer function G(s) = C(s)/R(s).<br>• A block multiplies its input by G(s).<br>• A summing point adds or subtracts signals.<br>• A take-off point copies a signal.<br>**Formula/Key:** C(s) = G(s)·R(s);   E(s) = R(s) − B(s)<br>G(s) transfer function, E error, B feedback signal | Three cards showing block, summing point and take-off point symbols. | Recall that a block is just a transfer function and the signal on the output side is the input multiplied by G(s). The summing point adds signals with the sign marked next to the arrow. The take-off point sends the same signal in two directions without loading it. These three symbols are enough to draw any linear control system. |
| 4 | Motivation: Many Loops, One Answer | • Real plants have several loops and branches.<br>• We need one overall transfer function C(s)/R(s).<br>• Reduction rules simplify step by step.<br>• Mason's formula gives the answer in one pass.<br>**Formula/Key:** Goal: replace a complex diagram by a single block  T(s) = C(s)/R(s) | Five-step reduction flow on the right (cascade → parallel → feedback → shift → repeat). | A motor speed controller has a current loop inside a speed loop inside a position loop. We cannot write one differential equation easily, but we can reduce the diagram. The rules we learn today are used in every later unit. Signal flow graphs are an alternative that avoids drawing the same blocks again and again. |
| 5 | Blocks in Cascade and in Parallel | • Cascade blocks multiply: G1·G2.<br>• Parallel blocks add or subtract: G1 ± G2.<br>• The sign follows the summing point.<br>• Order of cascade blocks does not matter (LTI).<br>**Formula/Key:** Cascade: G = G1 G2;   Parallel: G = G1 ± G2 | Two stacked diagrams: cascade and parallel, each with its equivalent single block. | When two blocks are in series, the output of the first is the input of the second, so the transfer functions multiply. When two blocks share the same input and their outputs are added, the transfer functions add. Pay attention to the sign at the summing point for the parallel case. These two rules solve many simple problems. |
| 6 | Feedback Loop Reduction | • Forward path G, feedback path H.<br>• Negative feedback subtracts at the summing point.<br>• Derive: C = G·E, E = R − H·C.<br>• Eliminate E to get the closed-loop transfer function.<br>• Unity feedback means H = 1.<br>**Formula/Key:** C/R = G/(1 + G·H)  (negative);   C/R = G/(1 − G·H)  (positive)<br>G forward gain, H feedback gain, GH open-loop gain | Standard feedback loop with E, G, H marked and the result printed below. | From the diagram, C equals G times E and E equals R minus H times C. Substitute and collect the C terms to get C over R equals G over one plus G H. The product G H is the open-loop transfer function and appears everywhere in stability analysis. For positive feedback the sign in the denominator changes. |
| 7 | Moving Take-off and Summing Points | • Shifting is needed when loops overlap.<br>• Take-off ahead of G: put G in the branch.<br>• Summing point beyond G: put 1/G in the branch.<br>• The signals at the outputs must stay unchanged.<br>**Formula/Key:** Rule: whatever you move across a block G, multiply by G (forward) or 1/G (backward) | Two before/after pairs: shifting a take-off point and shifting a summing point across a block. | Sometimes loops cannot be reduced because their take-off or summing points interleave. We move a point across a block and compensate in the branch so that every signal stays the same. Check each output signal after the move to make sure it is unchanged. Practise with two or three diagrams because this is the part that confuses students. |
| 8 | Block Diagram Reduction Procedure | • Combine cascade blocks.<br>• Combine parallel blocks.<br>• Reduce inner feedback loops first.<br>• Shift points to untangle overlapping loops.<br>• Repeat; finish with the outer loop.<br>**Formula/Key:** Work from the inside to the outside, one change at a time | Numbered five-step flow chart. | The order matters. Always look for cascade and parallel blocks first, then close the innermost feedback loop. Redraw the diagram after each step so that you do not lose a signal. If the diagram is stuck, shift a take-off or summing point. At the end you should have a single block with the overall transfer function. |
| 9 | Solved Example 1: Block Reduction | • Given the diagram: gain 4, then 1/(s+2) with inner feedback H1 = 1, and outer unity feedback. Find C/R.<br>• 1. Inner loop: G2/(1 + G2H1) = [1/(s+2)]/[1 + 1/(s+2)] = 1/(s+3).<br>• 2. Cascade with gain 4: 4/(s+3).<br>• 3. Outer unity loop: [4/(s+3)]/[1 + 4/(s+3)] = 4/(s+7).<br>**Formula/Key:** Answer: C(s)/R(s) = 4/(s + 7), a first-order system with pole at s = −7 | Left: steps; right: original diagram with inner and outer loops and the stepwise results. | Identify the innermost loop first, which is around the 1 over s plus 2 block. Close it using G over one plus G H. Multiply by the gain 4 in cascade and then close the outer unity feedback loop. Check the result at s equal to zero: the DC gain is 4 over 7, which matches the diagram, and the single pole at minus 7 tells us the system is stable. |
| 10 | Signal Flow Graph: Terminology | • Node: a variable; branch: a directed gain.<br>• Forward path: input to output, no node repeated.<br>• Loop: closed path, no node repeated.<br>• Non-touching loops share no node.<br>• Loop gain: product of branch gains in the loop.<br>**Formula/Key:** Source node: only outgoing branches;  sink node: only incoming branches | Signal flow graph with R→C on a line, a bypass path above and two feedback loops below, in colour. | A signal flow graph is a compact form of the block diagram. Variables become nodes and transfer functions become branches with arrows. A forward path runs from the input node to the output node without visiting a node twice. A loop starts and ends at the same node. Two loops are non-touching if they have no node in common. |
| 11 | Mason's Gain Formula | • One formula gives C/R directly from the graph.<br>• Δ uses single loops, then pairs of non-touching loops.<br>• Δk is Δ with loops that touch path k removed.<br>• Add the contribution of every forward path.<br>**Formula/Key:** T = Σ Pk·Δk / Δ;   Δ = 1 − ΣL₁ + ΣL₂ − ΣL₃ + …<br>Pk path gain, L₁ single loops, L₂ pairs of non-touching loops | Four cards defining Pk, Δ, Δk and L with the formula on top. | List all forward paths and all loops first. Then build Δ by subtracting the single loop gains and adding products of non-touching pairs. For each path find Δk by deleting loops that touch it. Finally divide the sum of Pk times Δk by Δ. Take care with signs: a negative feedback branch gives a negative loop gain. |
| 12 | Solved Example 2: Mason's Formula | • Graph with G1 = 2, G2 = 3, G3 = 1, G4 = 4, H1 = 1, H2 = 2 (as drawn). Find C/R.<br>• 1. Paths: P1 = G1G2G3 = 6;  P2 = G1G4 = 8.<br>• 2. Loops: L1 = −G1H1 = −2;  L2 = −G3H2 = −2.<br>• 3. L1 and L2 are non-touching: L1L2 = 4.<br>• 4. Δ = 1 − (−2 − 2) + 4 = 9.<br>• 5. Both paths touch both loops: Δ1 = Δ2 = 1.<br>• 6. T = (6 + 8)/9 = 14/9.<br>**Formula/Key:** Answer: C/R = 14/9 ≈ 1.56 | Left: steps; right: the signal flow graph with coloured paths and loops. | List the forward paths and the loops in a table so that you do not miss any. The two loops share no node, so they are non-touching and their product is added in Δ. Each forward path passes through at least one node of each loop, so both Δk are one. The final answer is 14 over 9. Ask students to verify by block reduction if time permits. |
