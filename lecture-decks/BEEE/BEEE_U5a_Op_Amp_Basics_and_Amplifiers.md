| 5 | Op-Amp Symbol and Ideal Characteristics | • Two inputs: inverting (−) and non-inverting (+).<br>• One output; dual supply ±VCC.<br>• Ideal: infinite gain, infinite input resistance.<br>• Ideal: zero output resistance, infinite bandwidth.<br>• Ideal: infinite CMRR, zero offset.<br>**Formula/Key:** Vo = A·(V+ − V−);   practical µA741: A ≈ 2×10⁵, Rin ≈ 2 MΩ, Ro ≈ 75 Ω | Table comparing ideal and typical µA741 parameters. | The op-amp amplifies the difference between its two inputs. The ideal op-amp has infinite open-loop gain, infinite input resistance, zero output resistance, infinite bandwidth and infinite common-mode rejection. A real device like the 741 is very close in the quantities that matter for our calculations, so the ideal assumptions give very good answers. |
| 6 | Op-Amp Specifications | • Input offset voltage: output error with zero input.<br>• Input bias current: small base currents of input stage.<br>• Slew rate: limits output speed, V/µs.<br>• CMRR: ability to reject common signals.<br>• Gain–bandwidth product: A × f = constant.<br>**Formula/Key:** Slew rate SR = dVo/dt∣max (V/µs);   fmax = SR/(2π·Vp) for an undistorted sine of peak Vp | Table of µA741 specifications with the meaning of each. | The data sheet lists practical limitations. The offset voltage shifts the output away from zero. The bias currents flow into the input terminals. The slew rate is the maximum rate at which the output voltage can change, which limits the frequency of large signals. The gain bandwidth product tells us that if we choose a gain of 10 the bandwidth is one hundred kilohertz for the 741. |
| 7 | Differential and Common-Mode Operation | • Differential signal: Vd = V1 − V2.<br>• Common-mode signal: Vc = (V1 + V2)/2.<br>• Op-amp amplifies Vd by Ad, Vc by Ac (small).<br>• CMRR measures how well Vc is rejected.<br>• High CMRR rejects noise picked up on both inputs.<br>**Formula/Key:** Vo = Ad·Vd + Ac·Vc;   CMRR = ∣Ad/Ac∣;   CMRR(dB) = 20 log₁₀∣Ad/Ac∣ | Op-amp with V1 and V2 inputs and four cards for Vd, Vc, Vo and CMRR. | Any pair of inputs can be split into a differential part and a common part. A good op-amp amplifies the difference by Ad and nearly ignores the common part, which is amplified by only a tiny gain Ac. The ratio of the two is the common-mode rejection ratio, 90 dB for the 741, meaning the common signal is reduced thirty thousand times relative to the difference. This is what allows small sensor signals to be recovered from noisy lines. |
| 8 | Negative Feedback and the Virtual Short | • Output fed back to the inverting input.<br>• Closed-loop gain ≈ 1/β, set by resistors.<br>• Because A is huge, V+ − V− ≈ 0: virtual short.<br>• Input current into the op-amp ≈ 0.<br>• Use these two rules for every circuit.<br>**Formula/Key:** Vo/Vin = A/(1 + Aβ) ≈ 1/β;   rules: V+ = V−,  I(in) = 0 | Feedback block diagram with the two analysis rules noted below. | With negative feedback the closed-loop gain depends only on the feedback network when the open-loop gain is very large. The output tries to keep the difference between the inputs at nearly zero, so the two input voltages are almost equal: this is the virtual short. Since the input resistance is very large, no current flows into the input terminals. With these two rules we can analyse any op-amp circuit with a few lines of algebra. |
| 9 | Inverting Amplifier | • Input applied through R1 to the (−) input.<br>• Non-inverting input grounded.<br>• Virtual ground at the (−) input.<br>• Current through R1 flows through Rf.<br>• Output is inverted.<br>**Formula/Key:** Vo = −(Rf/R1)·Vin;   Av = −Rf/R1;   Rin = R1 | Inverting amplifier circuit with R1 in series with the input, Rf in feedback and the non-inverting input grounded. | Because the non-inverting input is at ground, the virtual short makes the inverting input also zero volts: a virtual ground. The input current is Vin over R1 and, since no current enters the op-amp, the same current flows through Rf. The voltage across Rf is then the output voltage with a minus sign. The gain is the ratio Rf over R1 and the output is inverted. |
| 10 | Non-Inverting Amplifier | • Input applied directly to the (+) input.<br>• R1 and Rf form a divider from the output.<br>• V− = Vo·R1/(R1 + Rf) = Vin.<br>• Gain is 1 + Rf/R1, at least 1.<br>• Very high input resistance.<br>**Formula/Key:** Vo = (1 + Rf/R1)·Vin;   Av = 1 + Rf/R1<br>Voltage follower: Rf = 0, Av = 1 | Non-inverting amplifier circuit with R1 to ground and Rf in feedback. | In the non-inverting amplifier the input signal goes to the non-inverting terminal, so the input resistance is extremely high. The feedback resistors form a voltage divider on the output, and the virtual short forces the divided voltage to equal Vin. Solving gives a gain of one plus Rf over R1. If Rf is zero the circuit becomes a voltage follower, a buffer with gain one. |
| 11 | Summing Amplifier | • Several inputs, each through its own resistor.<br>• All join at the virtual ground.<br>• Currents add: I = V1/R1 + V2/R2 + V3/R3.<br>• Total current flows through Rf.<br>• Output is the inverted weighted sum.<br>**Formula/Key:** Vo = −Rf·(V1/R1 + V2/R2 + V3/R3)<br>R1 = R2 = R3 = Rf: Vo = −(V1 + V2 + V3) | Inverting summing circuit with three input resistors joined at the inverting input and Rf in feedback. | Each input drives a current through its own resistor into the virtual ground, and these currents add without interacting. The sum flows through the feedback resistor, producing a voltage with a negative sign. By choosing different resistor values we give each input its own weight. This circuit is used in audio mixers and in digital-to-analog converters. |
| 12 | Solved Example 1: Inverting and Non-Inverting | • (a) Inverting: R1 = 10 kΩ, Rf = 100 kΩ, Vin = 0.2 V. (b) Non-inverting: R1 = 1 kΩ, Rf = 9 kΩ, Vin = 0.5 V.<br>• 1. Inverting gain = −Rf/R1 = −10.<br>• 2. Vo = −10 × 0.2 = −2 V; Rin = 10 kΩ.<br>• 3. Non-inverting gain = 1 + Rf/R1 = 1 + 9 = 10.<br>• 4. Vo = 10 × 0.5 = +5 V.<br>**Formula/Key:** Answer: (a) Vo = −2 V;  (b) Vo = +5 V;  both within ±13 V swing | Left: steps; right: four cards with the gains and outputs. | For the inverting amplifier the gain is minus Rf over R1, minus ten. For the non-inverting amplifier it is one plus Rf over R1, plus ten. Check that the outputs are within the saturation limits of the op-amp, about 13 volts for a 15 volt supply. Note that the input resistance of the inverting circuit is R1 while that of the non-inverting circuit is very large. |
| 13 | Solved Example 2: Summing Amplifier | • Rf = 10 kΩ, R1 = 5 kΩ, R2 = 10 kΩ, R3 = 20 kΩ; V1 = 1 V, V2 = 2 V, V3 = −4 V. Find Vo.<br>• 1. Weights: Rf/R1 = 2, Rf/R2 = 1, Rf/R3 = 0.5.<br>• 2. Sum = 2 × 1 + 1 × 2 + 0.5 × (−4) = 2 + 2 − 2 = 2.<br>• 3. Vo = −2 V.<br>• 4. Check: output within ±13 V.<br>**Formula/Key:** Answer: Vo = −2 V | Left: steps; right: the summing circuit with values and the result. | Compute each input's weight as the ratio of the feedback resistor to its input resistor. Multiply by the input voltage and add, remembering the sign of V3. The total is plus two, and the output is its inverse, minus two volts. A final check on the output swing confirms that the op-amp is not saturated. |
