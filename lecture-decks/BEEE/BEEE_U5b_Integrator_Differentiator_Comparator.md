| 3 | Recap: What You Already Know | • Virtual ground at the inverting input.<br>• No current enters the op-amp.<br>• Capacitor: i = C·dv/dt;  v = (1/C)∫i dt.<br>• Inverting amplifier: Vo = −(Zf/Z1)·Vin.<br>**Formula/Key:** Generalised inverting amplifier:  Vo = −(Zf/Z1)·Vin;   capacitor impedance 1/(sC) | Inverting op-amp with R at the input and C in feedback (preview of the integrator). | The rules for an ideal op-amp with negative feedback, namely the virtual short and zero input current, still apply. The inverting amplifier formula holds with impedances in place of resistances. If we replace one resistor by a capacitor, the circuit performs calculus. Recall that the current through a capacitor is C times the derivative of its voltage. |
| 4 | Motivation: Calculus with Circuits | • Analog computers solve differential equations.<br>• Integrators in ADCs and PID controllers.<br>• Differentiators detect edges and rate of change.<br>• Comparators turn analog levels into logic.<br>**Formula/Key:** Three basic functions: ∫, d/dt and decision (comparison) | Summary table of integrator, differentiator and comparator input/output behaviour (preview). | An op-amp with a capacitor can integrate or differentiate a signal. | 5 | Op-Amp Integrator | • Resistor R at the input; capacitor C in feedback.<br>• Input current Vin/R charges the capacitor.<br>• Capacitor voltage is the integral of that current.<br>• Output is minus the integral of the input.<br>• Gain falls with frequency: low-pass.<br>**Formula/Key:** Vo(t) = −(1/RC)·∫Vin dt + Vo(0);   RC time constant (s)<br>In s-domain: Vo/Vin = −1/(sRC) | Integrator circuit: R from input to the inverting node, C from output back to it. | The input current is Vin divided by R because the inverting input is at virtual ground. All of it flows into the feedback capacitor, so the voltage on the capacitor is the time integral of the current divided by C. The output equals minus that voltage. For a constant input the output is therefore a ramp, whose slope is minus Vin over RC. |
| 6 | Integrator: Waveforms and Limitations | • DC input → linear ramp.<br>• Square-wave input → triangular output.<br>• Sine input → cosine (90° shifted).<br>• Offset causes drift until saturation.<br>• Fix: resistor Rf across C limits DC gain.<br>**Formula/Key:** Square ±V, half-period T/2: output swing = V·T/(2RC) (peak-to-peak)<br>Practical integrator: Rf ≈ 10 R in parallel with C | Square-wave input (dashed) and triangular output of the integrator. | A constant input produces a straight-line output, and a square wave therefore gives a triangular wave. The slope of each segment is minus the input amplitude over RC. A practical integrator has a problem with small DC offsets, which are integrated until the output saturates. A resistor across the capacitor limits the DC gain and avoids this drift, at the cost of a lower accuracy at very low frequencies. |
| 7 | Op-Amp Differentiator | • Capacitor C at the input; resistor R in feedback.<br>• Capacitor current = C·dVin/dt.<br>• That current flows through R.<br>• Output is minus RC times the rate of change.<br>• Gain rises with frequency: high-pass.<br>**Formula/Key:** Vo(t) = −R·C·dVin/dt;   in s-domain: Vo/Vin = −sRC | Differentiator circuit: C in series with the input, R in feedback. | In the differentiator the positions of R and C are swapped. The current through the input capacitor is C times the rate of change of the input voltage, and since there is virtual ground the same current flows through the feedback resistor. The output is therefore minus RC times the derivative of the input. A rising input produces a negative output and a falling input produces a positive output. |
| 8 | Differentiator: Waveforms and Limitations | • Triangular input → square output.<br>• Sine input → cosine output (amplitude × RCω).<br>• Amplifies high-frequency noise strongly.<br>• Can become unstable.<br>• Practical: series Rs with C and Cf across R.<br>**Formula/Key:** Vin = Vm sin ωt  →  Vo = −RC·ωVm cos ωt<br>Practical differentiator: add Rs (series with C) and Cf (across Rf) | Triangular input (dashed) and square output of a differentiator. | Differentiating a triangular wave gives a square wave, because the slope is constant on each segment. For a sine input the output amplitude is RC omega times the input amplitude, so high frequencies are amplified more, including noise. To make the circuit practical we add a small resistor in series with the input capacitor and a small capacitor across the feedback resistor to limit the high-frequency gain. |
| 9 | Op-Amp Comparator | • Op-amp used without feedback (open loop).<br>• Compares Vin with a reference Vref.<br>• Vin > Vref: output +Vsat.<br>• Vin < Vref: output −Vsat.<br>• Zero-crossing detector: Vref = 0.<br>**Formula/Key:** Vo = +Vsat if V+ > V−;   Vo = −Vsat if V+ < V−;   Vsat ≈ VCC − 1.5 V | Open-loop comparator with Vin and Vref and the square-wave output for a sine input. | In the comparator there is no feedback, so the huge open-loop gain drives the output to a saturation level for even a tiny difference between inputs. If the signal is at the non-inverting input and the reference at the inverting input, the output is high when the signal exceeds the reference and low otherwise. With zero reference the circuit detects zero crossings and converts a sine wave to a square wave. |
| 10 | Level Detector and Hysteresis | • Non-zero Vref sets the trigger level.<br>• Output is high only while Vin > Vref.<br>• Pulse width depends on Vref.<br>• Noise near the threshold causes chatter.<br>• Positive feedback (Schmitt trigger) adds hysteresis.<br>**Formula/Key:** Switching angle: θ = sin⁻¹(Vref/Vm);   high for 180° − 2θ each cycle | Sine wave, reference level, and the resulting output pulses (non-50 % duty). | A reference voltage other than zero shifts the switching instants. The output goes high when the sine passes the reference on the rising side and low when it falls below. The width of the output pulse therefore depends on the reference level, which is the basis of pulse-width control. In noisy environments a Schmitt trigger, which uses positive feedback to create two thresholds, avoids false switching. |
| 11 | Solved Example 1: Integrator | • R = 10 kΩ, C = 0.1 µF. Input: ±2 V square wave, frequency 500 Hz (half-period 1 ms). Find the output.<br>• 1. RC = 10 kΩ × 0.1 µF = 1 ms.<br>• 2. Slope = −Vin/RC = −2 V/1 ms = −2 V/ms (for +2 V).<br>• 3. In 1 ms the output falls by 2 V; with −2 V it rises by 2 V.<br>• 4. Output: triangular wave, 2 V peak-to-peak.<br>**Formula/Key:** Answer: triangular output, slope ∓2 V/ms, 2 V peak-to-peak (±1 V) | Left: steps; right: square input (dashed) and triangular output with the slope labelled. | First compute the time constant, 1 millisecond. For a constant input of 2 volts the output slope is minus two volts per millisecond. Since each half-period lasts one millisecond, the output changes by two volts, giving a triangular wave of two volts peak to peak centred on zero. Check that this does not exceed the saturation limit. |
| 12 | Solved Example 2: Differentiator | • R = 10 kΩ, C = 0.1 µF, Vin = 1·sin(2π × 500t) V. Find Vo.<br>• 1. RC = 1 ms; ω = 2π × 500 = 3142 rad/s.<br>• 2. dVin/dt = 1 × ω·cos ωt = 3142 cos ωt V/s.<br>• 3. Vo = −RC·dVin/dt = −10⁻³ × 3142 cos ωt.<br>• 4. Vo = −3.14 cos(2π × 500t) V.<br>**Formula/Key:** Answer: Vo = −3.14 cos ωt V (amplitude 3.14 V, 90° shifted, inverted) | Left: steps; right: the sine input and larger cosine output. | Differentiate the sine to get omega times cosine and multiply by minus RC. The output amplitude is 3.14 volts, more than three times the input, because the frequency is high enough that omega times RC is about three. At lower frequencies the gain would be smaller. The output is a cosine, so it is shifted by 90 degrees, and inverted. |
| 13 | Solved Example 3: Level Detector | • Vin = 5 sin ωt at the (+) input, Vref = +2 V at the (−) input, Vsat = ±13 V. Find the switching angles and the duty cycle.<br>• 1. Output high when 5 sin ωt > 2.<br>• 2. sin θ = 2/5 = 0.4 → θ1 = 23.6°.<br>• 3. θ2 = 180° − 23.6° = 156.4°.<br>• 4. High for 156.4° − 23.6° = 132.8° per cycle.<br>• 5. Duty = 132.8/360 = 36.9 %.<br>**Formula/Key:** Answer: Vo = +13 V for 23.6° < ωt < 156.4°, else −13 V; duty 36.9 % | Left: steps; right: the sine wave, the 2 V reference and the output pulses. | The output switches at the points where the input equals the reference. For a 5 volt sine and a 2 volt reference, the sine of the switching angle is 0.4, which is 23.6 degrees. By symmetry the falling crossing is at 156.4 degrees. The output is high between those two angles, so the positive pulse is about 133 degrees long in each cycle, a duty cycle of 36.9 per cent. |
